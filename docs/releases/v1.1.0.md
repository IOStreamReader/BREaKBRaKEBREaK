# BREaK!BRaKE!BREaK! v1.1.0

将网页刹车小游戏移植为 macOS 离线 App，使用 MacBook 力度触控板或支持 Force Touch 的妙控触控板按压力度控制制动。

- 相对力度阈值为 1～100%，默认 100%，设置会保存到本机。
- 未检测到兼容力度硬件时，提醒无法获得完整体验；确认后可以使用空格键或鼠标左键，保留原游戏持续按住逐渐加力的玩法。
- 删除在线功能，成绩及排行榜仅保存在本机。
- 修复右下角等待刹车图标的文字排版。
- 切换窗口或最小化时暂停游戏和音频。
- 启动弹窗包含生成式人工智能声明。

要求 macOS 13 或更高。解压后将 App 放入“应用程序”并打开。此版本使用本地 ad-hoc 签名，未经 Developer ID 签名或 Apple 公证。若系统阻止运行，请在确认来源后通过“系统设置 → 隐私与安全性”允许打开；无需关闭系统安全功能。

已在 Apple Silicon Mac 上完成原生运行验证，并通过 Rosetta 运行验证 Intel x86_64 程序；尚未在实体 Intel Mac 上实测。真实触控板手感需要在启动检测区体验。
