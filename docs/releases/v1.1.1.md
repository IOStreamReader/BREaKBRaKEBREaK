# BREaK!BRaKE!BREaK! v1.1.1

修复力度触控板检测完成后，按压“进入游戏”按钮产生的新力度信号使按钮被禁用、无法进入游戏的问题。

完成一次真实力度检测并松手后，校准结果会保持有效，普通菜单点击不再撤销校准。选择“重新检测”仍会清除旧结果，并要求完成新的检测。进入菜单的按压不会作为游戏制动输入。

增加了该点击顺序的回归测试，并在原生 WebKit 自检中验证检测、松手、按钮按压及进入游戏的流程。
